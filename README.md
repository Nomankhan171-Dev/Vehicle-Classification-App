# Vehicle Classification App

Vehicle image classification project built with Python, Streamlit and Machine Learning.

## Classes
- Car
- Motorcycle
- Bus
- Truck
- Van

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Train
Create:
```text
dataset/Car/
dataset/Motorcycle/
dataset/Bus/
dataset/Truck/
dataset/Van/
```

Then run:
```bash
python train_model.py
```

Streamlit main file:
```text
app.py
```
